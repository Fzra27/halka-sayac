# Halka Sayaç

Ubuntu ve Omarchy için tarayıcıda çalışan, Türkçe halkalı geri sayım sayacı. Süre azaldıkça halka küçülür. Sayacı duraklatabilir, kaldığı yerden devam ettirebilir veya sıfırlayabilirsin. Süre dolduğunda ses çalar.

GitHub’da **Code → Download ZIP** ile indir, arşivi aç ve `index.html` dosyasına çift tıkla. Firefox veya Chromium gibi güncel bir tarayıcı yeterli. İlk indirmeden sonra internet gerekmez.
